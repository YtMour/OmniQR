# OmniQR Android 发布检查清单

更新时间：2026-06-03

## 1. 真机功能复测

- 安装 APK 后可正常启动，图标、启动图和首页显示正确。
- 相机扫码可识别二维码，扫码结果会保存到记录并进入详情页。
- 扫码链接时会先显示安全确认，确认后才保存并进入详情页。
- 从相册识别二维码入口可用；如果当前平台能力不足，会显示降级提示。
- 普通文本、链接、WiFi、名片二维码可生成、预览、复制和保存记录。
- 保存二维码图片到相册可成功；失败时按设置进入图片预览。
- 另一台设备可识别 WiFi 二维码，手机联系人应用可识别 vCard 名片。
- 语言切换后，首页、生成页、记录页、设置页和隐私页文案刷新正常。

## 2. 权限核对

- 必需权限：相机、网络状态、WiFi 状态、震动、手电筒。
- 当前已移除首版不需要的高敏权限：账号、电话状态、读日志、写系统设置、挂载文件系统、修改网络状态、修改 WiFi 状态、唤醒锁。
- 发布前需要在打包产物中复查最终 `AndroidManifest.xml`，确认没有 HBuilderX 或插件重新注入无关权限。

## 3. 数据和隐私

- 隐私政策可从设置页进入。
- WiFi 密码、名片信息、扫码记录默认只存本地。
- JSON 导出会复制到剪贴板；H5 会额外下载 JSON 文件。
- JSON 导入会按记录类型和原始内容跳过重复记录。
- 清空非收藏、清空全部记录操作需要符合用户预期。

## 4. 发布产物

- `npm run build:h5` 构建通过。
- HBuilderX App 打包使用正式签名，不提交 keystore。
- 版本号、版本码、应用名、图标、启动图与 README 保持一致。
- 发布前不要把临时构建 hash 产物作为业务改动提交。

# OmniQR 当前实现状态

更新时间：2026-06-03

## 1. 当前完成状态

### 已完成

- 首页工具箱：支持进入扫码、普通二维码生成、WiFi 二维码、名片二维码、记录页和设置页。
- 普通二维码生成：支持文本、链接和自定义内容，点击生成后显示二维码并自动保存记录。
- WiFi 二维码：支持 SSID、密码、WPA/WPA2、WEP、无密码、隐藏网络和备注名称；点击生成后自动保存记录。
- 名片二维码：支持姓名、手机、公司、职位、邮箱、网址、地址、备注和记录备注名称；点击生成后自动保存记录。
- 二维码预览：使用本地二维码矩阵渲染，未生成前显示空状态，生成后显示更大且更紧凑的 OmniQR 外框、角落水印、随机二维码块造型和独立定位角造型。
- 图片导出：通过 canvas 生成带品牌外框、水印、二维码块造型和定位角造型的二维码图片；H5 或无相册权限时按设置降级为图片预览，并在 H5 尝试触发 PNG 下载。
- 记录管理：支持列表、搜索、类型筛选、收藏、结构化详情、复制、保存二维码图片、重新生成、删除、清空非收藏和清空全部记录；新生成记录会持久化当次二维码样式种子，详情页预览与保存导出保持同一套外框、颜色和模块造型。
- 设置页：支持默认记录标题、保存失败预览图片、二维码尺寸偏好、导出 JSON 到剪贴板和 H5 下载、导入 JSON 并按类型和内容去重、数据清理和恢复默认设置。
- Android 真机验证：相机扫码、扫码结果保存、相册保存、WiFi 识别和 vCard 导入主链路已验证，当前未发现明显问题。
- 扫码安全：扫码结果为链接时会先显示安全确认，确认后才保存并进入详情页。
- 相册识别：首页已提供从相册识别二维码入口；平台能力不足时显示降级提示。
- 二维码样式：默认尺寸已整体放大并压缩外框与二维码之间的留白，8 款风格、每款 10 款造型、10 类外框和单个随机水印已接入预览与导出图片；导出图片会把二维码绘制限制在外框安全区域内，避免相册保存后外框被二维码背景覆盖；二维码模块造型会经过扫码安全映射，在方块、软角、圆角和点块之间随机保留个性差异，定位角保持标准方形，避免空心、菱形、过度缩小等造型导致无法扫描；开启“固定自定义颜色”后才使用用户设置的前景色和背景色；同内容重复点击生成会刷新随机样式。
- Android 发布准备：已新增发布检查清单，并收敛首版不需要的高敏 manifest 权限。
- 国际化：已新增轻量 i18n 模块，设置页支持简体中文、繁體中文、English、Español、Français、Deutsch、日本語、한국어、Português、Русский、العربية、हिन्दी 等主流语言切换。主流程短文案、按钮、toast、表单占位、记录类型、设置项、隐私入口、隐私政策正文和免责声明均已覆盖到当前支持语言；缺失语言或异常语言值会安全回退到英文/简中，避免空白界面。
- 隐私政策：已提供独立隐私政策页面，覆盖本地生成、WiFi/名片敏感信息、记录存储、导出、权限、数据清理和免责声明。
- 文档体系：已维护 README、产品规划、路线图、UI 架构说明和当前实现状态。

## 2. 页面清单

- `pages/index/index`：首页工具箱和最近记录。
- `pages/generate/generate`：普通二维码生成。
- `pages/wifi/wifi`：WiFi 二维码生成。
- `pages/contact/contact`：名片二维码生成。
- `pages/records/records`：记录列表、搜索、筛选和收藏。
- `pages/detail/detail`：记录详情、WiFi/名片/链接/文本结构化展示、复制、重新生成、收藏和删除。
- `pages/settings/settings`：设置、导出、清理和隐私入口。
- `pages/privacy/privacy`：隐私政策和免责声明。
- `common/i18n.ts`：语言包、语言读取、语言切换和记录类型展示翻译。

## 3. 数据和隐私边界

- 当前不接入账号和云同步。
- 用户输入的二维码内容默认只保存在本机应用存储中。
- 设置页导出的 JSON 会复制到剪贴板；H5 环境会同时触发 JSON 文件下载。导入 JSON 时会按记录类型和原始内容跳过重复记录。二维码图片保存失败时，H5 会在打开预览的同时尝试下载 PNG。
- WiFi 密码、名片信息和扫码记录属于敏感数据，分享二维码图片前需要用户自行确认分享范围。
- 隐私政策页面已经说明本程序及本公司在法律允许范围内的责任限制。
- 语言偏好保存在本地设置中，不依赖账号或远程服务。
- 语言切换采用“选择语言 -> 保存设置 -> 当前设置页响应式更新”的流程，不需要返回首页才能看到新语言；设置页左上角返回按钮固定回到首页。
